# Privacy Policy for GDrive+

GDrive+ is an open desktop tool designed to manage files on Google Drive.

### Data Access and Storage
The application requests access to Google Drive solely to download, upload, and organize files selected by the user. All access tokens and downloaded data are processed and stored locally on the user's personal device.

### Data Sharing
GDrive+ does not collect, track, or share any personal user data or Google Drive files with third parties or external servers.

### Google API Limited Use Policy
GDrive+s use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
